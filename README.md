# ECUST 大学物理实验报告

基于 [Typst](https://typst.app/) 编写的大学物理实验报告模板与样例。

## 介绍

项目包括以下实验：

- 变阻器的使用与电路控制
- 霍尔法测量铁磁材料的磁滞回线和磁化曲线
- 动态悬挂法测定金属材料的杨氏模量
- 光的偏振
- 光电效应
- 元电荷测定——密立根油滴实验
- 声速测量
- 衍射光栅
- 线下选做实验：光速测量
- 线上选做实验：牛顿环法测曲率半径

## 使用方法

1. 安装 [Typst](https://github.com/typst/typst/releases)
2. 在 typ 文件里填入自己的信息和实验数据
3. 运行命令：

    ```bash
    typst c 实验名称.typ
    ```
